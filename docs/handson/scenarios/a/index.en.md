# Train and grade on EC2 GPUs (scenario A)

<span id="train-and-grade-on-ec2-gpus-scenario-a"></span>

<span id="scenario-a--train-and-grade-on-ec2-gpus"></span>

Two gVisor GPUs grade code generated by the EC2 training node. Start training after the `sandbox-gvisor-v1` pool passes [shared step 03 for A](../../common/03_pools/index.md#__tabbed_1_1).

## 1. Start GRPO training { #train }

For a first run, [train for five steps](grpo.md#__tabbed_1_1). Read the verdicts in `batch` and the model update on the next `train` line. For training alone, go to [cleanup](#cleanup).

## 2. Optionally switch grading pools { #switch }

To switch during training, [prepare four grading GPUs](pool_update.md#preparation-gpus-for-bluegreen) **before** starting the [60-step job](grpo.md#__tabbed_1_2). After the first v1 batch, [switch to v2](pool_update.md#run) in another terminal. Check a v2 verdict after `SWITCH` before scaling down v1.

## 3. Check the result and clean up { #cleanup }

Check the Job's `Complete` condition and the verdicts in `reward_batch`. To measure performance, run the [runtime benchmark](../../benchmarks/index.md#run-benchmark) after training ends. Keep the tunnel open for [cleanup](../../cleanup.md#cleanup-cdk).
